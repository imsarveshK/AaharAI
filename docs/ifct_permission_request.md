The Android catalog is blocked until ICMR-NIN grants written permission. Send the following to
the current official contacts `director.nin@icmr.gov.in` and `nin@nic.in`, and retain the reply

Subject: Permission request to use IFCT 2017 data in a non-commercial educational Android app

Dear Director / IFCT data team,

We are developing AaharAI, an open-source, non-commercial educational Android nutrition
tracking project for Indian users. We request written permission to extract and store selected
Indian Food Composition Tables 2017 records in the application for deterministic nutrition
calculations.

Proposed use:

- approximately 542 IFCT food records and only directly mapped published nutrient means;
- values identified as “per 100 g edible portion” with ICMR-NIN and IFCT 2017 attribution;
- no resale, advertising, subscription, or commercial use;
- no claim that national reference values are district-specific measurements;
- no use of AI to generate or alter nutrient values;
- source URL and food code retained for traceability;
- open-source Android application under GPLv3, with the IFCT data terms stated separately;
- public educational/research distribution through a source repository and possibly an APK.

Please confirm whether this use is permitted and state any required attribution, data-sharing,
redistribution, display, update, or reporting conditions. If a separate agreement or form is
required, please send it to us.
